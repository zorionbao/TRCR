# Reusable panel example group 4 | Joint portfolios and restoration success define resource requirements

These A–H examples use the input contract described in INPUTS.md. The article's main figures use the complete production source in Reproducibility_Code.zip.

A, C, E, Deterministic RIFT frontiers for the observed case portfolio, the product-of-marginals portfolio and a one-task-per-person policy in HRS, ELSA and CHARLS. The first color key identifies these allocation representations. Shading is pointwise 95% uncertainty from 1,000 multinomial portfolio draws. B, D, F, Attempt-resource frontiers for independent task successes at probabilities q = 0.25, 0.50, 0.75 and 1.00, identified by the second color key. All task attempts cost one unit, including unsuccessful attempts; task capacities are unrestricted. G, Independent-success minus perfectly-correlated-success optimized residual risk at q = 0.50, with identical marginal success probabilities, observed portfolios and budgets. Positive values indicate lower residual risk under correlated success; negative values indicate lower residual risk under independent success. The dotted line denotes equality. H, Minimum attempt budget needed to halve each cohort's baseline multiple-difficulty risk under independent success; points show attainable targets. The cohort key applies to G-H. The success kernels specify final task states for every source-state and attempted-subset pair, while budget and capacity constraints count attempted tasks. Success probabilities and costs are planning inputs. All data axes measure 46 by 40 mm, and each cohort retains its observed next-interview case distribution.

Source data: `Figure4_capacity_opportunity.csv`. Panels A-F and G retain every budget on the 61-point grid. A, C and E include every bootstrap interval on that grid. H retains all attainable targets on the 21-point task-success probability grid.
